# 0x1LOG

0x1LOG uses the `nahiarhdlog` distribution for embedded observability for FastAPI. Installing `0x1-log` installs that distribution and uses the same Python API.

```bash
pip install 0x1-log
```

```python
from nahiarhdLOG import observe
```

Existing projects can continue installing `nahiarhdlog` directly.

[Documentation and examples](https://github.com/raihan0x1/nahiarhdlog#readme)
