# 0x1LOG

0x1LOG provides embedded observability for FastAPI. Installing `0x1-log` provides the `ox1log` import and installs the `nahiarhdlog` library it uses.

```bash
pip install 0x1-log
```

```python
from ox1log import observe
```

Existing projects can continue installing `nahiarhdlog` directly and importing `nahiarhdLOG`. For library submodules, keep importing from `nahiarhdLOG`.

[Documentation and examples](https://github.com/raihan0x1/0x1-log#readme)
